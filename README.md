
# SARA

Special Application Ranging Area

TUI Application Launcher - System Navigator - Terminal Decorator

<img src="https://www.hakipaks.org/glamour_shots/sara3.jpg" width="200px">

Acquire [release](https://www.hakipaks.org/sara) and run `make` to generate config.h

Edit config.h to keymap commands, launch custom nestable menus, and configure builtin function keys.

Speedily navigate your Linux system via three builtin methods.

Update the fg[], bg[] and hd[] ascii art arrays. Color and position them to your preference.

Chain and combine navigation, application, and command-launching keys to create keyboard motions that execute your common terminal tasks in the fewest possible keystrokes.

[Getting Started](https://www.hakipaks.org/sara/getting-started)
